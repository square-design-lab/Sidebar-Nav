Where this goes

        
    
          
  1. Copy the code with the button in the header.
    2. 
          
  2. In Squarespace, open Settings → Advanced → Code Injection and paste it into Header. The sidebar is site-wide, so it belongs there rather than on one page.
    3. 
          
  3. Save, then open your live site in a new tab.
    4. 
        

        
Pasting into Footer works too, but the native top bar flashes before the sidebar takes over.

      

      

        
Good to know

        
    
          
  1. Your header is the sidebar. Nothing is copied or rebuilt — the real logo, cart, social icons and button are moved into the column, so the live cart count keeps updating and your theme's styling still applies.
    2. 
          
  2. Nothing to list. Every nav link and folder is read from your header as-is. Add a page in Squarespace and it appears in the sidebar.
    3. 
          
  3. Mobile is untouched. Below the breakpoint the native header comes back exactly as Squarespace rendered it — only folders open as accordions.
    4. 
          
  4. Folders open on click, never hover. Keyboard users get a real aria-expanded button, Escape closes an open folder, and the current page is marked with aria-current.
    5. 
          
  5. Reduced motion is respected. Visitors who ask for it get instant open/close instead of the slide.
    6. 
          
  6. An announcement bar is lifted to the top of the page so it still spans the full width.
    7. 
          
  7. The plugin stands down inside the Squarespace editor so you can still edit your header.
    8. 
        

      

      

        
If something looks off

        
    
          
  1. The sidebar appears over a mobile header. Your site switches to its mobile header wider than 767px — raise Sidebar active above to match.
    2. 
          
  2. A logo is too wide. Set Logo width under Styling; the image scales down and keeps its ratio.
    3. 
          
  3. A section pokes out sideways. Leave Clip sideways overflow on.
    4. 
          
  4. Nav links look cramped. Raise Space between links, or lower Nav size.
